## 3. ILLUSTRATIVE DATA DISCLAIMER

**Current disclaimer text:** "Illustrative view of key features."
**Styling:** .portal-preview-subtitle — 13px italic, color #9ca3af, positioned above the tab strip

**Is it sufficient to cover all panel content?** Yes. It appears before any tab content renders. All mock card data (Maria D., Juan P., ABC Company, XYZ Corp, "12 applicants", "82% complete", job names, statuses) is clearly illustrative.

**Visibility concern (accessibility, not copy quality):**
- #9ca3af on white #ffffff has an approximate contrast ratio of 2.85:1
- WCAG AA requires 4.5:1 for normal text; 3:1 for large text
- At 13px italic, this fails both thresholds
- Recommended: change to #6b7280 (~4.6:1) to pass WCAG AA while keeping visual de-emphasis
- This is an accessibility backlog item, not a copy quality change
